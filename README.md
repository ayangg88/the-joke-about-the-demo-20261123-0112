A one-line joke about working beside an AI coding agent, written for a room watching a demo:

> My agent fixed the crash by making the demo crash faster — 'same bug, but now it fails with confidence.'

## Run it

```sh
python3 main.py
```

It writes the joke to `/output/entry.txt` (one line, UTF-8). Python 3.13, standard library only, no network.
